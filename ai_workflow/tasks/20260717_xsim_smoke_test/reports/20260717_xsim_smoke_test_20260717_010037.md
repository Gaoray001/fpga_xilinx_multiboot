## 调用链说明

1. Shell：用户后续运行 `./scripts/vivado2018_common.sh xsim-smoke`。
2. Shell 入口设置 run 目录、logs 目录、artifacts 目录，并调用：
   - `vivado -mode batch -source tcl/sim/xsim_smoke.tcl`
3. Tcl：`tcl/sim/xsim_smoke.tcl` 后续在 Vivado Tcl 环境中调用：
   - `xvlog` 编译 `rtl/hdl/user/xsim_smoke_dut.v` 和 `sim/tb/tb_xsim_smoke.v`
   - `xelab` elaboration `xil_defaultlib.tb_xsim_smoke`
   - `xsim` 运行 snapshot，并传入 batch Tcl：`log_wave -recursive *; run all; quit`
4. Testbench：`tb_xsim_smoke.v` 完成复位、启动、done 脉冲和结果值自检。
5. PASS/FAIL：testbench 打印 `RESULT=PASS` 或 `RESULT=FAIL fail_count=<N>`；Tcl 扫描 xsim log，发现 FAIL 或缺少 PASS 时 `error`。

## 仿真输出与 PASS/FAIL 查看方法

- 通过统一 Shell 入口运行后，主 run 目录形如：
  - `_runs/common_vivado/<timestamp>_xsim-smoke/`
- XSim 相关日志形如：
  - `_runs/common_vivado/<timestamp>_xsim-smoke/logs/xsim_smoke_xvlog.log`
  - `_runs/common_vivado/<timestamp>_xsim-smoke/logs/xsim_smoke_xelab.log`
  - `_runs/common_vivado/<timestamp>_xsim-smoke/logs/xsim_smoke_xsim.log`
- 判断口径：
  - `xsim_smoke_xsim.log` 含 `RESULT=PASS` 且不含 `RESULT=FAIL`，才可记录为 smoke test PASS。
  - `xsim_smoke_xsim.log` 含 `RESULT=FAIL`，或缺少 `RESULT=PASS`，应记录为 FAIL。
  - Shell 入口最终退出码应与 Tcl error 状态一致。
