## Before your first build

The build chain needs these environment variables (see
`tcl/build/01_create_project.tcl` header comment for the full list):

- `COMMON_VIVADO_PART_NAME` — **required**, no built-in default. Example:
  `export COMMON_VIVADO_PART_NAME=xc7vx690tffg1927-2`
- `COMMON_VIVADO_TOP_MODULE` — optional, defaults to `Top`.
- `VIVADO_SETTINGS` — optional, defaults to
  `/tools/Xilinx/Vivado/2018.3/settings64.sh`.

Then add your project content:
- RTL into `rtl/hdl/user/` and `rtl/hdl/import/`.
- Xilinx IP Tcl exports (`write_ip_tcl`) into `tcl/ip/`.
- Top-level XDC into `constraints/`.

## Common commands

```bash
export COMMON_VIVADO_PART_NAME=<your_part>
COMMON_VIVADO_SKIP_IP_GEN=1 ./scripts/vivado2018_common.sh create   # smoke test project assembly
./scripts/vivado2018_common.sh open                                 # verify open/rebuild
./scripts/vivado2018_common.sh full                                  # synth -> impl -> bit (single process)
./scripts/vivadogui.sh                                               # open the latest project in Vivado GUI
```

Staged commands (`synth`/`impl`/`bit`) do **not** chain across separate invocations —
each call gets a fresh timestamped run directory. Use `full` for a single connected build.
See the copied `tcl/build/common_utils.tcl` for the full mechanism.
